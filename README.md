# SunPilot

Property management for Sunseeker Rentals.

Styles are written in SCSS under `styles/`. `npm start` compiles them to `public/styles.css`.

```powershell
npm install
npm start
```

To recompile while the server is already running: `npm run styles`. `npm run styles:watch` recompiles on each save.

Open http://localhost:3000
